## 使用规则

ADR 记录高影响、长期或难以逆转的技术选择。编号一经使用不复用；接受后的 ADR 不直接改写结论，使用新 ADR 标记“取代”。状态可为：`提议`、`已接受`、`已拒绝`、`已取代`、`已废弃`。

文件名格式：`NNNN-简短标题.md`。创建步骤：复制 [`0000-模板.md`](0000-模板.md)，分配下一个编号，填写选项与后果，在本索引登记，并由受影响模块负责人评审。
