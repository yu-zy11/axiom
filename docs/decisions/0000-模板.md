# ADR-NNNN：标题

- 状态：提议
- 日期：YYYY-MM-DD
- 决策者：角色或团队
- 关联：需求 ID、Issue、MR、被取代 ADR

## 背景

描述要解决的问题、约束和不决策的代价。只陈述形成选择所需的事实。

## 决策驱动因素

- 可衡量的目标或硬约束。

## 备选方案

1. 方案 A：优势、代价和风险。
2. 方案 B：优势、代价和风险。

## 决策

说明选择、适用范围和生效条件。

## 后果

### 正面

- 获得的收益。

### 负面与风险

- 接受的代价，以及如何监控或缓解。

## 验证与复审

- 如何证明决策有效。
- 在什么信号或日期复审。
