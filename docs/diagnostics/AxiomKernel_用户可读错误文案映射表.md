# AxiomKernel 用户可读错误文案映射表

本文档定义 `AxiomKernel` 内部错误码到用户可读文案的映射规则，目标是为上层 CAD、脚本平台、自动化工具和 Web/桌面 UI 提供统一、清晰、可本地化的错误提示文本。

## 1. 文档目标

本文档用于明确：

- 哪些错误码需要用户可读映射
- 用户看到的文案应如何组织
- 技术错误与用户提示如何分层
- 建议的操作指引模板

## 2. 设计原则

用户可读错误文案必须满足以下原则：

- 尽量解释“发生了什么”
- 尽量提示“可以怎么做”
- 不把底层算法实现细节直接暴露给普通用户
- 同一错误码在同一产品内的表达保持稳定
- 支持后续多语言本地化

## 3. 文案结构建议

每条映射建议至少包含：

- `错误码`
- `短文案`
- `详细说明`
- `建议动作`
- `是否适合直接展示给终端用户`

推荐数据结构：

```json
{
  "code": "AXM-BOOL-E-0005",
  "title": "布尔运算失败",
  "message": "模型在局部区域无法稳定分类，当前运算未能完成。",
  "suggestion": "请尝试简化接触区域、减小局部复杂度，或启用修复模式后重试。",
  "userVisible": true
}
```

## 4. 展示分层建议

### 4.1 面向终端用户

建议展示：

- 短标题
- 简短说明
- 一条可执行建议

避免展示：

- 复杂数值术语
- 内部模块名
- 多层嵌套错误栈

### 4.2 面向高级用户或工程师

可以额外展示：

- 主错误码
- 诊断 ID
- 关联实体
- 详细技术说明

## 5.4 布尔错误

| 错误码 | 用户短文案 | 详细说明 | 建议动作 |
|---|---|---|---|
| `AXM-BOOL-E-0001` | 布尔输入无效 | 参与运算的实体不合法、不可用或运算类型无效。 | 请先验证输入实体，并使用已声明的 BooleanOp 枚举值。 |
| `AXM-BOOL-E-0003` | 布尔求交失败 | 系统未能稳定计算局部相交关系。 | 请减少复杂接触区域，或先修复输入模型。 |
| `AXM-BOOL-E-0004` | 真实交线切分失败 | 面三角化、交段约束覆盖或整边邻接无法形成一致切分，阶段 bool.split。 | 检查输入裁剪环、方向与模型尺度，并保存诊断；失败没有可用的部分分片。 |
| `AXM-BOOL-E-0005` | 布尔分类失败 | 模型在局部区域无法稳定判断内外关系。 | 请尝试简化模型、调整局部容差，或开启修复模式。 |
| `AXM-BOOL-E-0006` | 布尔重建失败 | run_rebuilt无法形成流形边界、Strict验证失败或受限Safe失败；按bool.rebuild/validate/repair区分，底层原因保留。 | 请检查输入模型有效性，或改用分步布尔操作。 |
| `AXM-BOOL-E-0010` | 布尔结果为空 | 运算结果为空或不符合预期。 | 请确认两个实体确实存在有效重叠关系。 |
| `AXM-BOOL-E-0011` | 当前输入不支持布尔准备或分类 | 模型表示、曲面/曲边或代理边界超出第一代平面直边闭壳范围，或请求了 ExactCritical。 | 使用真实平面直边闭壳及已支持的浮点模式；不要把代理模型当精确实体。 |
| `AXM-BOOL-E-0012` | 布尔准备或分类超出预算 | 面比较、每面边数、交段、累计切分/邻接/分类、内部共面裁剪/探针/重建/Safe工作、片数或点数超过声明预算。 | 简化模型或在公开上限内调整预算；兼容 run 每面最多 256 边。 |
| `AXM-BOOL-E-0013` | 布尔几何或内外位置无法可靠分辨 | 坐标尺度、近平行面、远交线、未解析边界容差带或有效射线不足/分歧。 | 检查模型尺度与诊断阶段，保留证据；不要猜测内外或显示为空交集，也不保证调整容差即可成功。 |
| `AXM-BOOL-E-0014` | 只读准备不支持共面区域 | 候选面在容差内共面，需要二维区域求交，包括面接触或相同体。 | 当前准备入口会保守拒绝此场景；不要将其显示为成功或零交段。 |

cycle-0080 按 `Issue.stage` 展示“候选对检查”（bool.prep.candidates）、“几何求交”（bool.intersect）或“真实面边界裁剪”（兼容 run 的 bool.intersect.trim）。E-0001 在这些阶段也表示开壳、损坏关联或真实短边，需结合 status 与报告说明，不只提示无效句柄。失败始终保留 diagnostic_id、无部分结果；prepare 成功的零交段是合法边界空交（分离或包含），不能误报材料体积为零。只读准备与已回归裁剪读取失败不污染输入和调用者活动事务；该历史包不认证兼容run后续重建；cycle-0082真实入口支持另见§5.4下述说明。完整范围见 [支持矩阵](../api/AxiomKernel_详细模块接口清单.md#821-stage-4-第一代求交准备支持矩阵cycle-0080--s4-intersection)。

cycle-0081 再按 `Issue.stage` 展示“真实交线切分”（bool.split）和“实体内外分类”（bool.classify）；先行求交拒绝仍展示原候选/求交阶段。E-0001 在新入口也涵盖非法片数选项、非有限点和闭壳输入不一致。新分类拒绝实际使用 E-0013，旧 E-0005 不是本包的新拒绝码。Boundary 只代表可解析实际裁剪边界并返回 FaceId，不能将整个容差带视为边界；仅近边界不确定点明确拒绝。新入口只读，失败无部分结果，仅新增诊断，活动事务可继续写入和回滚；摘要/PCurve 覆盖及实体重建限制见 [本批支持矩阵](../api/AxiomKernel_详细模块接口清单.md#822-stage-4-第一代切分与实体分类支持矩阵cycle-0081--s4-split-classify)。

cycle-0082新增真实run_rebuilt：展示“实体重建”（bool.rebuild）、“Strict验证”（bool.validate）、“保持真实边界的Safe修复”（bool.repair），复用E-0006且保留底层cause、稳定status与JSON证据。内部共面/面相切和同形支持见 [真实支持矩阵](../api/AxiomKernel_详细模块接口清单.md#823-stage-4-真实实体重建支持矩阵cycle-0082--s4-rebuild)；公开只读prepare仍以E-0014拒绝共面。近共面间隙/短非零交段以E-0013/bool.intersect拒绝，边点Union或夹点以E-0006/bool.rebuild拒绝。Safe只消除人工共面内边和一致共线节点，真实短特征或二次认证失败仍明确拒绝，不能提示“打开修复就会成功”。空交/完全减除返回Ok与output=nullopt，不显示为E-0010错误；不创建bbox/mesh替代体。失败恢复模型/Eval/cache，保留诊断与递增ID、活动writer，回滚输出不复活且可重试，合法累计遥测不回退。认证只限固定嵌入平面直边double参考，不表示曲面或全局嵌入证明。

## 5.7 查询分析错误

| 错误码 | 用户短文案 | 详细说明 | 建议动作 |

cycle-0075 的真实多面体截面完全无交集、纯线/点相切均为成功，不能显示“截面计算失败”；兼容 section 此时返回 `MeshId{}`。解析曲面体与旧占位体显示 `AXM-CORE-E-0004` 的不支持提示；截面无法分辨才使用 `AXM-QUERY-E-0002 / query.section.numeric`。位置容差不将近邻平面吸附或将正间隙解释为相交。

## 9. 测试要求

用户可读文案映射表也需要测试。

必测项：

- 每个 `P0` 错误码都存在用户文案映射
- 同一错误码在 UI 层文案一致
- 缺失映射时存在默认回退文案

## 10. 结论

这份映射表的作用是把底层错误体系转化为上层用户真正能理解的提示层。只要错误码稳定、文案映射清晰，上层产品就能在不暴露复杂实现细节的前提下，给用户足够有帮助的反馈。

### S3-MASS 质量查询文案（cycle-0076）

按 `Issue.stage` 区分同一稳定错误码的使用场景，不新增错误码。`query.mass_properties.support_gate` 搭配 `AXM-CORE-E-0004` 时可显示“当前模型不支持质量分析”，说明“该模型没有受支持的真实边界，或原生解析模型已被编辑”，建议使用支持的真实建模路径；metadata 恢复、历史占位 thicken 记录/布尔代理体不提示为“质量为零”。cycle-0077 真实平面 Face thicken 支持当前拓扑质量，见下节。`preflight` 提示目标已删除或边界不完整；`numeric` 提示尺度或惯性数值不稳定。失败均没有可显示的部分质量，不能填入 bbox 估算值。回滚可恢复编辑前支持状态，提交后的原生解析编辑仍不支持。

### S3-MODELING 建模文案（cycle-0077）

复用既有码，按 `Issue.stage` 显示失败位置。extrude/revolve/sweep/loft 的 `input_gate` 提示检查显式轮廓、轴/角度、有限导轨或截面数，`materialization` 提示输入不能形成受支持的闭壳；直线 sweep 的错误仍显示扫描阶段。

| thicken 阶段 / 码 | 建议文案 / 处理 |
|---|---|
| input_gate / AXM-CORE-E-0001 | “目标面不存在”，重新获取有效 FaceId |
| input_gate / AXM-MOD-E-0003 | “厚度必须有限且为正”，输入正厚度 |
| topology_gate / AXM-MOD-E-0003 | “面边界或支撑平面无效”，检查定向边链、直线支撑/裁剪区间、平面归属与法向 |
| support_gate / AXM-CORE-E-0004 | “加厚仅支持真实平面直边面”，曲面/曲边/代理面不提示为成功或零质量 |
| materialization / AXM-MOD-E-0003 | “面区域或厚度无法形成有效闭壳”，检查自交、孔冲突或当前尺度无法分辨的厚度 |

沿支撑法向单侧加厚，不按环绕向猜测方向；失败没有结果体，保留原模型和活动事务，可回滚后重试。真实平面 thicken 已支持当前拓扑质量与空间查询；编辑为曲面时 query.mass_properties.support_gate 仍提示不支持，不显示旧缓存属性。支持范围与实际回归见 [API §8.1.1](../api/AxiomKernel_详细模块接口清单.md#811-stage-3-五类建模主路径cycle-0077--s3-modeling)。
